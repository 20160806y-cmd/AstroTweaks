Что делает каждый файл пакета `astrotweaks.Multiverse`:

---

1. **`MultiverseDims.java`** — Регистрация ID измерений в `DimensionType` и `DimensionManager`. Каждый уровень занимает 4 подряд ID (base, base+1, base+2, base+3) + глобальный -1000000. Потокобезопасна через `synchronized`, корректно обрабатывает повторный запуск JVM (переиспользует существующие `DimensionType` через `getById`, не дублируя через `EnumHelper`), но всегда перерегистрирует в `DimensionManager` (тот живёт одну серверную сессию).

2. **`LevelData.java`** — Иммутабельный POJO-дескриптор одного мультивселенского уровня: name, number (слот 1..MAX), uid (8-хеш), baseId (базовый ID измерения), seed, folder. Содержит методы `dimensionId(type)` и `typeOf(dimId)` для маппинга между `LevelDimensionType` и глобальными ID.

3. **`LevelDimensionType.java`** — Перечисление четырёх «внутренних» измерений каждого уровня: `OVERWORLD`, `NETHER`, `END`, `DEPTHS`.

4. **`LevelManager.java`** — Центральный менеджер (синглтон). Отвечает за:
   - **Реестр уровней**: чтение/запись `registry.dat` (список уровней с name, number, baseId, seed, uid).
   - **Привязка к сейву**: папка `MULTIVERSE/` живёт внутри текущего мира, marker-файл `universe.dat` связывает реестр с конкретным save.
   - **Глобальный мир**: папка `MULTIVERSE_GLOBAL` вне сейва (в корне `.minecraft`/сервера).
   - **Создание/уничтожение уровней**: `getOrCreateLevel` (по имени или по номеру слота), `recycleLevel` (удаление мира и освобождение слота max).
   - **Создание WorldServer**: `constructWorld` — ручная сборка `WorldServer` с `LevelSaveHandler`, спавн, End-портал (обсидиановая платформа строится всегда для END-измерений, даже если `level.dat` уже существует — т.к. он общий для всех 4-х измерений уровня), регистрация через `DimensionManager.setWorld`.
   - **Персистентность игроков**: `recordPlayer` / `clearPlayer` / `restorePlayer` — сохранение позиции игрока в `mv_playerdata.dat` и восстановление при повторном логине.
    - **Выгрузка**: `unloadWorldNow` (гарантированное снятие с тик-листа + аннулирование измерения в `DimensionManager`, чтобы горячая подгрузка phantom-мира не могла восстановить его в пустоту с чужим save handler), `processDeferredUnloading` (отложенная выгрузка пустых миров: измерение выгружается через `MV_DeferredUnloadingMS`, если за это время никто не вошёл; phantom-миры (созданные горячей подгрузкой Forge) используют ту же тайм-логоску, но никогда не сохраняются; карта `pendingUnload` живёт в `MultiverseEvents`, задержка кешируется из `ModVariables` при загрузке мира), `unloadAndUnregisterAll` (останов сервера).
   - **Очистка фантомных DIM-папок**, миграция legacy-папки, расчёт seed через uid-хеш.
   - **Фантомные миры**: при выгрузке мира `unloadWorldNow` отменяет регистрацию измерения в `DimensionManager` (prevent горячей подгрузки phantom `WorldServerMulti` с чужим save handler).

5. **`LevelSaveHandler.java`** — Наследник `AnvilSaveHandler`, корневой папкой которого является `MULTIVERSE/<name>`. Отключает проверку `session.lock` (три измерения уровня делят одну папку, перезапись timestamp ломала бы сессию).

6. **`MultiverseWorldProviders.java`** — Набор `WorldProvider`-ов для каждого типа измерения:
   - `MultiverseOverworld` — наследует `WorldProviderSurface`, переопределяет `getDimensionType()` на ванильный OVERWORLD (для корректного ответа `BlockFire`).
   - `MultiverseHell` — наследует `WorldProviderHell`, respawn в owning overworld.
   - `MultiverseEnd` — наследует `WorldProviderEnd`, respawn в owning overworld.
   - `MultiverseDepths` — кастомный провайдер: генератор и биом из `DepthsDim`, полная тьма, без погоды/сна/света, чёрный туман.
   - `MultiverseGlobal` — void-мир (`VoidDimension.ChunkProviderModded`), биом VOID, нет погоды/сна.

7. **`MultiverseEvents.java`** — Glue-класс, привязывающий мультивселенную к Forge-событиям:
   - `WorldEvent.Load(dim 0)` → вызывает `LevelManager.onWorldLoaded` (привязка к сейву).
   - `PlayerLoggedInEvent` → отложенное `restorePlayer` на следующий тик.
   - `EntityTravelToDimensionEvent` → **перехват портала**: если существо внутри MV-уровня, vanilla-назначение отменяется и перенаправляется на свой уровень (`resolvePortalTarget`). Глобальный мир недоступен (portals запрещены).
   - `BlockEvent.PortalSpawnEvent` → **создание портала**: в глобальном мире — не обрабатывать. В MV overworld/nether — отмена vanilla-зажигания + ручная замена на `BlockNetherPortal` через `NetherPortalGeometry`.
   - `PlayerChangedDimensionEvent` / `PlayerLoggedOutEvent` → `recordPlayer`/`clearPlayer`.
    - `ServerTickEvent` (каждые 160 тиков) → `processDeferredUnloading` (включая phantom-миры, которые теперь тоже проходят через deferred-timer, а не выгружаются немедленно) + `NetherPortalLink.onEndTick`. `MV_PROXY` исключается из `reconcileWithDisk` (не переносится в `MULTIVERSE_ERRORED`).

8. **`MultiverseTeleporter.java`** — Реализация `ITeleporter`. Ставит существо на точную позицию вместо vanilla-маппинга. Поиск безопасного Y через столбец с расширением по чанкам (до 512 блоков). При `createExitPortal=true` строит стандартный обсидиановый 2x3 портал + огонь (для обратного прохода через vanilla-систему).

9. **`MultiverseUtil.java`** — Утилита для GUI (ARK/TDARK): маппинг относительных ID измерений (0, -1, 1, -6000) в абсолютные через `resolveRelativeDim`, определение anchor-уровня (`anchorBaseOf`), проверка принадлежности к одной вселенной (`isSameUniverse`).

10. **`CommandMultiverse.java`** — Команда `/mv join <layer_id> [dim_id] [seed]` и `/mv get`. Поддерживает: возврат в оригинальный мир (0), переход в глобальный (-), переход по номеру/имени уровня с указанием типа измерения и seed. `/mv get` выводит текущую позицию игрока в мультивселенной.

11. **`MessageMultiverse.java`** — Пакет `server → client` через `SimpleNetworkWrapper`. Содержит `baseDimId`, флаг `global`, и `seed`. Клиентский обработчик (`ClientHandler`) вызывает `MultiverseDims.registerLevelDimensions/registerGlobalDimension` и через рефлексию устанавливает seed в `WorldInfo`. Это необходимо ПЕРЕД respawn-пакетом, иначе клиент не знает DimensionType для нового измерения.

12. **`NetherPortalGeometry.java`** — Геометрические хелперы для кастомного портала:
    - `findFrame` / `compute` — полный аналог vanilla `BlockPortal.Size`: обход рамки из обсидиана, поиск ширины/высоты/оси.
    - `findInterior` — дополнительная проверка, что все внутренние клетки — блоки портала.
    - `placePortal` — заполнение рамки кастомными блоками портала.
    - `findNearbyPortal` — поиск существующего кастомного портала в радиусе 128 блоков (как vanilla Teleporter, но от центра).
    - `placeExitPortal` — постройка 2x3 портала с обсидиановой рамкой на земле.

13. **`NetherPortalLink.java`** — Серверная логика перемещения через кастомный портал:
    - Каждое касание портала увеличивает счётчик (80 тиков = порог, как ванильный).
    - Ссылка из `TileNetherPortal` используется для телепортации в точку привязки (двусторонний линк).
    - Если ссылка невалидна — ищет ближайший существующий портал или строит новый, затем связывает оба.
    - Отложенный execute через `addScheduledTask` (безопасно внутри `Entity.move()`).
    - `onEndTick()` — очистка протухших pending-сущностей, убывание счётчиков для не-в порталах.

14. **`NetherPortalReg.java`** — Регистрация блока `BlockNetherPortal` и `TileNetherPortal` через `RegistryEvent.Register<Block>` (аннотация `@Mod.EventBusSubscriber`). Срабатывает только при `ModVariables.MULTIVERSE == true`.

15. **`BlockNetherPortal.java`** — Кастомный блок портала (наследник `BlockPortal`). Визуально/механически как vanilla (бонд-бокс, текстура, звуки, свечение 0.75), но: `onEntityCollidedWithBlock` делегирует в `NetherPortalLink.handleCollision`, `neighborChanged` уничтожает блок если рамка сломана, создаёт `TileNetherPortal` ( имеет TileEntity). Singleton через `BLOCK`.

16. **`TileNetherPortal.java`** — TileEntity для блока портала. Хранит «маяк»: `hasLink`, `linkDim`, `linkX/Y/Z`, `linkAxis`. Все блоки одного портала хранят одинаковый линк. Сериализация через NBT.

---

**Схема взаимодействия (усиленно)**:
```
CommandMultiverse  ─┐
MultiverseEvents   ─┤─► LevelManager ──► MultiverseDims (регистрация ID)
MineDimEnter        │         │                │
ArkTransferHelper   │         ▼                ▼
TDArkGUI            │   LevelSaveHandler   MultiverseWorldProviders
                    │         │
                    └─────────┘──► MessageMultiverse (сервер→клиент)

Порталы: BlockNetherPortal ─► NetherPortalLink ─► NetherPortalGeometry
                                                    │
                                                    ▼
                                              TileNetherPortal (хранит линк)
```
